# 安装与环境搭建

> 一句话心智模型：**Go 环境 = 三件事——GOROOT（装在哪）+ GOPATH（在哪干活）+ GOPROXY（从哪拿依赖）。装好 Go 之后 90% 的"环境问题"都出在这三个变量上。**

## 一、安装 Go

### 方式 1：官方二进制包（推荐，版本新且可控）

Linux（本机场景）：

```bash
# 1. 下载对应平台的包（版本号按官网最新改）
wget https://go.dev/dl/go1.22.2.linux-amd64.tar.gz

# 2. 若之前装过旧版本，先清掉
sudo rm -rf /usr/local/go

# 3. 解压到 /usr/local/go
sudo tar -C /usr/local -xzf go1.22.2.linux-amd64.tar.gz

# 4. 加入 PATH（写进 ~/.bashrc 持久生效）
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
source ~/.bashrc
```

macOS：`brew install go`；Windows：官方 msi 安装包，或 `winget install GoLang.Go`（安装后 PATH 自动配置）。

### 方式 2：系统包管理器（省事但版本可能滞后）

```bash
sudo apt install golang-go
```

- Ubuntu/Debian 会装在 `/usr/lib/go-<ver>`（本机 1.22.2 即来自 apt）
- 缺点：系统源里的版本通常落后于官方，且路径非标准。**学习/生产建议用官方包**

### 方式 3：版本管理器（多版本切换）

`gvm`、`asdf`、`goenv` —— 需要同时维护多个 Go 版本时再用，单版本不必引入。

## 二、验证安装

```bash
go version          # go version go1.22.2 linux/amd64
go env GOROOT       # /usr/lib/go-1.22
```

## 三、三个关键环境变量（环境问题的 90% 根源）

| 变量 | 含义 | 本机值 |
|------|------|--------|
| GOROOT | Go 装在哪（标准库 + 工具链） | `/usr/lib/go-1.22` |
| GOPATH | 你在哪干活（工作区） | `/home/ydqun/go` |
| GOPROXY | 模块从哪下载（代理链） | `https://proxy.golang.org,direct` |

### GOROOT — 装在哪

- 定位安装目录，里面是标准库源码和编译工具链
- **现代 Go 不用手动设置**，go 二进制能自己定位；只有装到非标准路径时才需要显式指定

### GOPATH — 在哪干活

默认 `~/go`，分三个子目录：

```
~/go
├── bin/   # go install 产出的可执行文件（gopls 等工具都进这里）
└── pkg/   # 编译缓存 + 模块缓存（源码包缓存）
```

> 旧版还有 `src/`，是 module 时代之前的工作区约定；Go 1.16+ 默认开启 module 后基本用不到了。

### GOPROXY — 从哪拿依赖

- 模块代理，格式是**逗号分隔的代理链**，前一个失败才试下一个，`direct` 表示直连上游
- 默认 `https://proxy.golang.org,direct`
- 国内加速：`export GOPROXY=https://goproxy.cn,direct`
- 企业内部私服：配合 `GOPRIVATE` 跳过代理直连

## 四、编辑器配置

- **VS Code + Go 扩展**（官方，依赖 `gopls` 语言服务器）
- 首次安装扩展后它会提示安装 `gopls`、`dlv` 等工具，也可手动装：

```bash
go install golang.org/x/tools/gopls@latest   # 语言服务器，进 $GOBIN
```

- 常用能力：保存自动格式化（gofmt）、函数签名 hover、自动补全、go doc 悬停

## 五、高频命令速查

| 命令 | 作用 |
|------|------|
| `go env` | 查看/设置全部环境变量 |
| `go mod init <module>` | 初始化模块（生成 go.mod） |
| `go run main.go` | 编译并直接运行 |
| `go build` | 编译产出可执行文件 |
| `go test` | 运行测试（`-v` 详细、`-run` 筛测试名） |
| `go vet` | 静态检查可疑代码 |
| `gofmt` / `go fmt` | 统一代码格式 |
| `go install pkg@latest` | 安装工具到 GOBIN |
| `go doc fmt.Println` | 命令行查文档 |

## 六、第一个程序

```go
package main

import "fmt"

func main() {
	fmt.Println("hello, go")
}
```

```bash
go run hello.go   # hello, go
```

`hello.go` 属于 `main` 包 → `go run` 把它当可执行入口。模块、包、构建的关系详见后续章节。

## 小结

- 装好 Go = 三件事搞清楚：**GOROOT 装在哪、GOPATH 在哪干活、GOPROXY 从哪拿依赖**
- 日常开发只需记住：源码放任何目录都能建 module，`go run` 跑、`go build` 出产物、`go mod` 管依赖
- 环境排查顺序：`go version` → `go env GOROOT` → `go env GOPROXY`
