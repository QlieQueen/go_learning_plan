# 03-控制结构

> 一句话心智模型：**程序 = 数据 + 道路规划。Go 把控制流削减到最少——只有一个 `for`、一个 `switch`，其余靠"编译还原"覆盖。**

核心哲学：**极简原语 + 用组合代替新增语法**。C 里 while/do-while/switch 穿漏的坑，Go 用"一个 for + 自动 break"全部收编。

---

## 一、if：条件分支 + 初始化语句

### 心智模型

if 是岔路口。Go 的 if 比 C 多一个能力：**条件前可以声明变量，作用域只在 if-else 块内**。

这是错误处理的惯用法：

```go
if err := doSomething(); err != nil {
    return err
}
```

取错误 + 判断错误一行搞定，错误变量不会泄漏到块外。

### 三种写法

```go
if 条件 { ... }
if 条件 { ... } else { ... }
if 条件 { ... } else if 条件 { ... }
```

### 手写验证

```go
if n := 7; n%2 == 0 {
    fmt.Println(n, "是偶数")
} else {
    fmt.Println(n, "是奇数") // else 分支也能看到 n
}
// fmt.Println(n) // ✗ 编译错误：undefined: n —— 出了 if-else 块就没了
```

## 二、for：唯一的循环

### 心智模型

Go **没有 while、没有 do-while**。循环只有 `for` 一个关键字——少一个关键字，就少一种心智负担。

三种形态覆盖一切场景：

| 形态 | 写法 | 等价 |
|------|------|------|
| 完整三语句 | `for init; cond; post {}` | C 的经典 for |
| 只有条件 | `for cond {}` | C 的 while（编译还原） |
| 死循环 | `for {}` | `while(true)`，靠 break/return 退出 |

配套：`break`（退出当前循环）、`continue`（跳过本次循环体）。

### 编译还原

```go
// while (n < 3) { n++ }   → 还原成
for n < 3 { n++ }
```

### 手写验证

```go
// 形态一：完整三语句
for i := 0; i < 3; i++ { fmt.Printf("%d ", i) }   // 0 1 2

// 形态二：只有条件 = while
n := 0
for n < 3 { n++ }                                   // n 变 3 退出

// 形态三：死循环 + break
count := 0
for { count++; if count >= 3 { break } }            // count 到 3 退出
```

## 三、switch：和 C 彻底不同

### 心智模型

C 的 switch 是**跳表**：case 必须是编译期常量（跳表要算偏移），不写 `break` 就一路穿下去。

Go 把这两条全改了：

1. **顺序匹配**：按源码顺序求值，**第一个为真的 case 执行，执行完自动跳出**（编译器在每个 case 末尾隐含插入 break）
2. **case 是任意表达式**：不是跳表，不需要编译期常量

### 五个要点

```go
// ① 表达式 case（C 里做不到）+ 顺序匹配
x := 10
switch x {
case x / 2: // x/2 = 5 ≠ 10，跳过
    fmt.Println("case x/2 命中")
case 10:
    fmt.Println("case 10 命中")
}

// ② 多值 case
switch 2 {
case 1, 3, 5: fmt.Println("奇数")
case 2, 4, 6: fmt.Println("偶数")
}

// ③ fallthrough：想穿下去必须显式写
switch 1 {
case 1:
    fmt.Println("one")
    fallthrough // 无条件穿进下一个 case 的 body
case 2:
    fmt.Println("two")
}

// ④ 无条件 switch = if-else 链（编译还原的活证据）
switch {
case score >= 90: fmt.Println("A")
case score >= 80: fmt.Println("B")
default:          fmt.Println("C")
}
```

**⑤ fallthrough 的语义（重点）**：`fallthrough` **不重新求值**下一个 case 的条件，直接穿进它的 body 执行。危险就在这——可能把你带进本不该进的 case。

比喻：switch 找 case = **按门铃找对的房间**；`fallthrough` = 进门后**不检查下一扇门，直接穿墙**进下一间屋子执行。

硬约束：
- 必须是 case 的**最后一条语句**（后面不能再有代码）
- **不能用在最后一个 case**（没有下一个房间可穿）
- 不能用于 type switch（接口章节再提）

### 陷阱：break 只退 switch，不退循环

```go
for i := 0; i < 3; i++ {
    switch i {
    case 1:
        break // 这里 break 退的是 switch！for 照常继续
    }
    fmt.Printf("%d ", i) // 0 1 2 全打印
}
```

### label：跳出多层循环

```go
outer:
for i := 0; i < 3; i++ {
    for j := 0; j < 3; j++ {
        if i == 1 && j == 1 {
            break outer // 命名标签，直接跳出两层
        }
        fmt.Printf("(%d,%d) ", i, j)
    }
}
// (0,0) (0,1) (0,2) (1,0)
```

### 手写验证（含 fallthrough 不重新求值）

```go
probe := func() int {
    fmt.Println("[probe] case 2 的条件被求值了！") // 若 fallthrough 会重新求值，这行会出现
    return 2
}
switch 1 {
case 1:
    fmt.Println("one")
    fallthrough
case probe():
    fmt.Println("two")
}
// 输出（注意【没有】[probe] 那一行）：
//   one
//   two
// → 证明 fallthrough 跳过条件求值，无条件穿进 body
```

## 小结

- **极简原语 + 编译还原**：while → `for cond`、switch 自动 break → 隐含 break、无条件 switch → if-else 链
- **if 初始化语句**：取错误 + 判断一行搞定，作用域只在块内，错误变量不泄漏
- **switch 与 C 的三大差异**：顺序匹配（非跳表）、case 可表达式、fallthrough 必须显式
- **break 陷阱**：switch 里的 break 只退 switch；多层循环用 `label` + `break label`
